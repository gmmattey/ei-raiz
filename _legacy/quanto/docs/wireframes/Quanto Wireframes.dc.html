Direção de design
Calmo, confiante,
quase nada de UI.
Um número manda. Todo o resto serve a ele — hierarquia agressiva.
Respiro generoso. Margens largas, poucos elementos por dobra.
Mono-cor. Petróleo é a marca; verde/vinho só para sinal.
Shell fixo. Header e tab fixos; só o miolo rola.
Fix 01
O Hero
Antes: bloco lotado (saudação + label + número + ganho + resgate + frescor empilhados). Agora: hero imersivo só com o número-tese e um chip de ganho. Frescor e alocação viram cards brancos abaixo.
Fix 02
Fim do "samba" no Safari
Shell position:fixed com header e tab travados; um único miolo rola com overscroll-behavior:contain. safe-area-inset respeitada — sem bounce, sem barra pulando.
Fix 03
Tab bar maior
De 52px para 64px + safe-area. Ícones 24px, alvos de toque cheios, rótulos sempre visíveis e estado ativo em petróleo sólido.
Antes → Depois
As duas mudanças de maior impacto, lado a lado.
