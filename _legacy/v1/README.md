# Esquilo Invest

Dashboard financeiro inteligente criado em Google Apps Script para consolidar carteira, analisar risco e gerar recomendações assistidas por IA.

## Objetivo

Transformar dados financeiros dispersos em uma visão única e prática do portfólio, sem executar ordens de investimento.

## Funcionalidades

- Consolidação de carteira de investimentos
- Análise de ações, fundos e previdência
- Score de risco do portfólio
- Alertas e recomendações estratégicas
- Apoio de IA para interpretação dos dados

## Tecnologias

- Google Apps Script
- HTML, CSS e JavaScript
- Integrações com planilhas e serviços de IA

## Escopo e limitações

Este repositório representa a primeira geração do produto. A evolução estrutural do Esquilo Invest ocorre em repositórios mais recentes, sem que esta base deixe de servir como referência histórica e funcional.

O sistema não realiza compra, venda, custódia ou movimentação de ativos.

## Status

Legado funcional em manutenção. Novas evoluções devem priorizar a arquitetura mais recente do ecossistema Esquilo Invest.

## Documentação
