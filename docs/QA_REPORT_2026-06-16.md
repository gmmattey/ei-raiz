## O que foi validado

### Fluxos principais (api.spec, auth.spec, e2e.spec, cvm.spec, ai.spec)

- Registro, login e recuperacao de senha (API e UI)
- Isolamento por usuario via JWT
- `GET /api/portfolio` com resumo, frescor, benchmarks macro e bens
- CRUD de ativos e aportes com calculo automatico de invested
- Snapshot manual e snapshot cron mensal
- Busca de fundos CVM por nome e CNPJ, parser ZIP/CSV
- Importacao XLSX wizard 3 etapas (upload → revisao → confirmar)
- Ocultar valores e persistencia de preferencias no localStorage
- Navegacao mobile entre Hoje, Carteira, Historico, Importar e Bens
- Cadastro, edicao e exibicao de bens (FGTS, IMOVEL, VEICULO)
- Historico de preco BRAPI por ativo (1mo, 3mo, 6mo, 1y)
- Detalhe de ativo com contexto de portfolio e lista de aportes

### Caminhos negativos (validation.spec — novo)

- `POST /api/assets` — 6 casos de validacao (institution, classe, ticker/qty, cvm_cnpj+ticker)
- `PUT /api/assets/:id` — body vazio, status/institution invalidos
- Idempotencia de snapshot (segundo call → `created: false`)
- `GET /api/funds/search` com query ausente ou < 3 chars → `{results: []}`
- `GET /api/portfolio` sem token → 401; portfolio vazio → zeros/arrays vazios
- `POST /api/goods` — tipos IMOVEL/VEICULO validos e invalidos, fields obrigatorios
- `PUT /api/goods/:id` body vazio → 400; `DELETE /api/goods/99999` → 404
- Aportes em classes que nao aceitam (POUPANCA, COFRINHO) → 422
- Validacoes de aporte: amount ≤ 0, sem contributedAt, data futura, ativo inexistente
- `GET /api/assets/:id/history` em ativo manual → 422; id inexistente → 404
- Registro de email duplicado → 409
- Recuperacao de senha com CPF errado, data errada, email inexistente, senha curta → 400
- Isolamento multi-user de bens (UserB nao acessa bens do UserA)
- `PUT /api/assets/:id` nao sobrescreve invested quando contributions ja existem
